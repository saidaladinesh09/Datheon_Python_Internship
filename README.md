# Hangman Word Guessing Game

## Project Description
A console-based Hangman game developed using Python.

## Features
- Random word selection from a text file
- Letter guessing
- Hidden word display
- ASCII Hangman drawing
- Prevents duplicate guesses
- Maximum 6 wrong attempts
- Input validation

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the command:

python hangman.py
